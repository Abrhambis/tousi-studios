# Tousi Studios

Website for Tousi Studios Inc. A single page (`index.html`) with its films, images and fonts in `assets/`.

## Live preview

Published with GitHub Pages from the `main` branch.

## Before launch

- Set `FORM_ENDPOINT` near the bottom of `index.html` to a form service (for example Formspree) so inquiries reach Julia's inbox.
- Point the tousistudios.com domain at GitHub Pages, or upload these files to the current host.
